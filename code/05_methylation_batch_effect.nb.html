Methylation platform harmonization and batch-effect assessment

Scope

This notebook documents how the methylation batch effect was identified and corrected. TCGA methylation data generated with the Illumina HumanMethylation27 and HumanMethylation450 platforms were harmonized, and the effect of BMIQ normalization was assessed using probe-design distributions and the LAML platform comparison shown in Supplementary Figure 6.

LAML was the only tumor type for which the same 194 samples were profiled on both the 27K and 450K platforms. This paired setting allowed the platform effect to be evaluated without differences in sample composition. LAML was therefore reserved for this validation and was not included in the downstream harmonized methylation matrix.

The complete normalization workflow is computationally intensive. The reduced checkpoint needed for Supplementary Figure 6 is included in data/processed/.

Identification of the 450K probe-design bias

The beta-value distributions of Infinium type-I and type-II probes were compared within each tumor type. Their displaced distributions identified the probe-design bias in the unnormalized 450K data. The resulting diagnostic plots are retained in Methylation_batch_ correction_result/plot_bias/.

BMIQ correction of 450K data

The unchanged BMIQ v1.3 implementation described by Teschendorff et al. was used to correct the Infinium type-II probe-design bias. The implementation uses RPMM and was run independently for every sample with the parameters shown below.

data_finale <- list()
for (i in 1:length(vet)) {
  mat <- meth_450_finale[[i]]
  ind <- rowSums(is.na(mat)) == ncol(mat)
  mat <- mat[!ind, ]

  mat <- mat %>%
    mutate(
      type = case_when(
        rownames(mat) %in% probe_I$CpG ~ "1",
        rownames(mat) %in% probe_II$CpG ~ "2"
      )
    ) %>%
    relocate(type) %>%
    filter(!grepl("^rs", rownames(.)))

  sample <- as.vector(substr(colnames(mat[-1]), 1, 12))
  result <- list()
  betas <- list()

  for (k in 2:ncol(mat)) {
    beta.v <- as.vector(mat[, k])
    design.v <- as.vector(mat$type)
    samp <- sample[k - 1]
    result[[sample[k - 1]]] <- BMIQ(
      beta.v,
      design.v,
      nL = 3,
      doH = TRUE,
      nfit = 50000,
      th1.v = c(0.2, 0.75),
      th2.v = NULL,
      niter = 5,
      tol = 0.001,
      plots = FALSE,
      sampleID = samp
    )
    ttt <- data.frame(
      type = design.v,
      beta = result[[k - 1]][[1]],
      row.names = rownames(mat)
    )
    colnames(ttt)[2] <- samp
    betas[[sample[k - 1]]] <- ttt
  }

  col_list <- lapply(betas[-1], function(x) x[, 2])
  finale <- data.frame(
    betas[[1]],
    do.call(cbind, col_list),
    row.names = rownames(betas[[1]])
  )
  colnames(finale) <- gsub("\\.", "-", colnames(finale))
  data_finale[[vet[i]]] <- finale

  flag <- finale %>%
    filter(type == "1")
  flag1 <- finale %>%
    filter(type == "2")

  prova <- melt(
    flag,
    id.vars = "type",
    variable.name = "gene",
    value.name = "metilazione",
    na.rm = TRUE
  )
  prova1 <- melt(
    flag1,
    id.vars = "type",
    variable.name = "gene",
    value.name = "metilazione",
    na.rm = TRUE
  )
  prova2 <- rbind(prova, prova1)

  a <- ggplot(prova2, aes(x = metilazione, color = type)) +
    geom_density(alpha = .5) +
    ggtitle(vet[[i]]) +
    xlab("beta value") +
    labs(color = "probe types")
  a
}

Platform harmonization

Probes containing SNPs at the CpG interrogation or single-base extension positions were removed. The 27K data were converted to the 450K representation, and only CpGs shared by the two platforms were retained.

cpg_comuni_piattaforme <- function(meth_data_450, meth_data_27) {
  risultati_450 <- list()
  risultati_27 <- list()
  cpg_comuni <- intersect(
    rownames(meth_data_27[[1]]),
    rownames(meth_data_450[[1]])
  )
  risultati_27 <- lapply(
    meth_data_27,
    function(x) x[cpg_comuni, , drop = FALSE]
  )
  risultati_450 <- lapply(
    meth_data_450,
    function(x) x[cpg_comuni, , drop = FALSE]
  )
  return(list(
    risultati_27 = risultati_27,
    risultati_450 = risultati_450
  ))
}

merge_common_data <- function(HM_27, HM_450) {
  common_names <- intersect(names(HM_450), names(HM_27))
  merged_list <- list()
  for (name in common_names) {
    merged_list[[name]] <- rbind(HM_450[[name]], HM_27[[name]])
  }
  for (name in setdiff(names(HM_450), common_names)) {
    merged_list[[name]] <- HM_450[[name]]
  }
  return(merged_list)
}
